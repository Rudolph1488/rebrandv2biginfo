# Інтеграції та Вебхуки (Per-Tenant)

[← Повернутися на головну Вікі](./README.md)

Усі ключі інтеграцій зберігаються окремо для кожної компанії в таблиці `integration_channels` і доступні лише адміністраторам цієї компанії.

---

## 1. Прийом замовлень із сайтів / B2B (Webhook)
* **Ендпоінт:** `POST /api/webhooks/orders/[channelId]` ([route.ts](../src/app/api/webhooks/orders/%5BchannelId%5D/route.ts)).
* **Де взяти URL і ключ:** у робочому просторі відкрийте **Налаштування → Інтеграції** → додайте канал (*Сайт Weblium*, *B2B Портал* або *Власний сайт*) → скопіюйте **Webhook URL** та **`x-api-key`**.
* **Логіка роботи:**
  1. Перевіряє `x-api-key === webhook_secret` (для `b2b` та `custom_webhook`).
  2. Шукає клієнта в межах `org_id` за телефоном; якщо немає — створює нового.
  3. Створює замовлення на першому етапі канбану компанії з поміткою `source_name = channel.name`, парсить місто/відділення з `shipment.address_custom` (для Weblium) та опції товару (`options`, `variant`, `sku`) в `attributes`.
  4. **Автосинхронізація товарів (`products`):** для кожної позиції шукає товар у каталозі за `sku` або назвою (`name`); якщо товару ще немає в базі — автоматично створює його в Номенклатурі (`products`) і прив'язує `product_id`.
  5. **Автозарахування в Касу (`order_paid` / `paid: true`):** при події онлайн-оплати (наприклад, Weblium `event: "order_paid"`) автоматично створює прибуткову транзакцію в `cashflow_transactions` (із захистом від дублювання при повторних вебхуках) і переводить замовлення з першого етапу на другий (наприклад, «Підтверджено»).

## 2. Нова Пошта API
* **Серверний проксі:** `POST /api/integrations/novaposhta` ([route.ts](../src/app/api/integrations/novaposhta/route.ts)).
* **Як працює:** бере `apiKey` з `integration_channels` (`type = 'novaposhta'`) конкретної компанії та підтримує 3 дії:
  * `action: 'cities'` — пошук населеного пункту.
  * `action: 'warehouses'` — пошук відділення/поштомату в місті.
  * `action: 'create_ttn'` — автоматично підтягує відправника з кабінету НП компанії, створює контрагента-отримувача, генерує ЕН (ТТН) та записує її в замовлення.

## 3. Telegram-бот
* У **Налаштування → Інтеграції** вже можна зберегти `Bot Token` для кожної компанії.
* *У планах (Спринт В):* реалізувати ендпоінт `/api/webhooks/telegram/[channelId]` та розділ «Комунікації» для переписки.
