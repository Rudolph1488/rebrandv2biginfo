# CENTRUM OS (CRM v2) — База знань та Документація

> Повна технічна та користувацька Вікі мультитенантної CRM-платформи **CENTRUM OS** (Next.js App Router + Supabase PostgreSQL + Tailwind CSS).

---

## Зміст Вікі

1. **[Архітектура та Стек](./architecture.md)** — як влаштована система, мультитенантність, права доступу (RBAC + RLS), швидкодія та дизайн-система.
2. **[База даних та Міграції](./database.md)** — опис усіх таблиць PostgreSQL, зв'язків, тригерів, Storage-бакетів та історія міграцій.
3. **[Модулі CRM (Посібник користувача)](./modules.md)** — детальний туторіал по кожному розділу: Суперадмінка, Онбординг, Замовлення, Клієнти/Досьє, Склади, Постачання, Каса, Налаштування.
4. **[Інтеграції та Вебхуки](./integrations.md)** — підключення Нової Пошти, сайтів (Weblium, B2B, власні сайти) та формат запитів.
5. **[Міграція з Firebase v1 та Деплой](./migration-and-deploy.md)** — скрипти перенесення бази з v1, локальний запуск та чеклист виходу на Vercel.

---

## Швидкий старт (локально)

```powershell
cd a:\centrum-v2
npm run dev
```

* Локальна адреса: `http://localhost:3000` (або `3001`, якщо `3000` зайнятий).
* Змінні середовища: [.env.example](../.env.example) → скопіювати в `.env.local`.

## Поточний статус проєкту
* **Ядро платформи:** Авторизація, Суперадмінка, Інвайти, Onboarding Wizard, Workspace Switcher — **Готово**.
* **Модулі MVP:** Огляд, Замовлення (Канбан + Список + Картка замовлення + оплата в Касу в 1 клік + автосписання + створення ТТН Нової Пошти в 1 клік), Клієнти (+ Досьє + real-time пошук), Номенклатура, Склади, Постачання, Каса, Налаштування (4 вкладки), Вбудована Вікі (`/wiki`) — **Готово**.
* **Перенесені дані (компанія `REBRAND`):** 3 851 клієнт, 12 товарів, 900 замовлень.
* **Наступний етап:** Telegram-бот для сповіщень та оперативки → Деплой на Vercel.
